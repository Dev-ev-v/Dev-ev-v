## Projects

### Doggy-notes
[doggy-notes](https://github.com/Dev-ev-v/doggy-notes)

A cross-platform, local-first CLI note-taking application built with Python.

Designed for private, lightweight note-taking, it includes tags, a trash system, and import/export functionality. It can be used as a personal diary or simply as a place to keep everyday notes.

I'm working toward future improvements, including backup options and stronger data security.

### PMP
[pmp](https://github.com/Dev-ev-v/pmp)

A lightweight, cross-platform music player for the terminal, built with Python and powered by mpv.

Inspired by music players like Lark Player and Spotify, PMP focuses on local playback without depending on online services. It includes queue controls, shuffle, looping, per-track statistics, a miniplayer, and session recovery.

The goal is simple: make local music playback reliable, practical, and accessible directly from the terminal.
